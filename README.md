# Easyliao Client

这是一个使用 Qt 开发的桌面应用程序聊天工具，使用了 LGPL/GPL 授权的模块（core gui multimedia network xml webenginewidgets webchannel）。

## 开源声明

本项目依赖 Qt 框架，使用 Qt 的开源模块，遵循 LGPL v3 与 GPL v3 协议要求：
- 本项目使用 **动态链接方式** 链接 Qt。
- 未修改 Qt 源码。
- 所有许可证文本请见项目 `licenses/` 目录。
- 用户可替换 Qt 动态库，请参考 `source_links/qt_linking_instructions.txt`。

## 项目结构

- `src/`：项目源代码目录
- `licenses/`：包含 LGPLv3 和 GPLv3 正文
- `notice/`：包含版权、商标信息与免责任声明
- `source_links/`：动态链接替换说明
